二、上传期初库存文件

▼

每月 4 日 03:00（北京时间）系统自动从 SAP 导出上个月物料库存作为期初库存；也可随时手工上传 Excel，或点击「从 SAP 取数」。自动取数不会执行计算，仍需点击「加载数据并自动计算」。

📁 首页

操作步骤

  1. 正常情况下无需每月手工导 SAP：计划任务会在每月 4 日 03:00 导出上个月 ZMMR0010N_Y 数据并写入期初库存。首页状态条会显示来源为「SAP 期间」。
  2. 取数失败或需要补跑时，在首页点击 从 SAP 取数；或继续使用 期初库存文件上传 覆盖当前文件。
  3. 期初库存更新后，点击 加载数据并自动计算（或「重新计算」），系统再完成数据处理。
如果非首次上传，数据源不会改变，每月更新一次即可。SAP 自动取数与手工上传都会先备份旧文件再覆盖。上传/取数后请再点击“加载数据并自动计算”。定时任务须在手工跑通整条链路后再安装；每日备份仍为 02:00。

三、基础数据维护

▼

基础数据维护模块包含10个子模块，用于管理系统中各项基础配置数据。每个子模块遵循统一的编辑流程：少量数据直接在页面编辑/删除，大量数据下载模板后批量导入，编辑完成后返回数据管理主页点击"同步数据"。

通用操作流程

  1. 编辑数据：少量时直接在页面点击编辑或删除按钮操作；量大时点击"下载模板"获取维护模板，填写后"批量导入数据"
  2. 返回数据管理主页，点击"同步数据"按钮，编辑结果同步给其他用户
  3. 对方收到提示后可"立即刷新"或"稍后刷新"。若暂未收到提示，等待5-10分钟后再查看

3.1 物料映射关系

📁 数据管理 → 物料映射

当系统中新增物料时，需要维护物料与对应拆解产物的映射关系。若物料类别发生变动，也需要在此处进行相应修改，以确保系统运行时能准确识别物料归属。

通用操作 — 同步数据与刷新

编辑完成后，需返回数据管理主页进行数据同步，其他用户才能看到更新。同步后对方会收到提示，可选择立即刷新或稍后刷新。

3.2 减扣规则管理

📁 数据管理 → 减扣规则

适用于转投、一类二次拆解加工、一类三次拆解加工、荧光灯处置、印刷板处置等场景。当一类拆解规则发生变动时，需要对减扣规则进行相应修改。

3.3 产品拆解系数管理

📁 数据管理 → 产品拆解系数管理

修改旧机产品拆解为一类拆解物料的系数，即各旧机产品（电视、电脑、冰箱、空调、洗衣机等）拆解后各类拆解产物的产出比例系数。

3.4 深加工数据管理

📁 数据管理 → 深加工数据

修改一类拆解物料进行深加工的投料和产出系数，即一类拆解产物进一步加工为深加工产物时的物料投入与产出比例关系。

3.5 计件人工标准数据维护

📁 数据管理 → 计件人工标准数据

当人工计件单价发生变动时，需在此处维护各岗位的计件单价数据。系统根据此基准数据自动计算计件工资。

3.6 薪酬及社保基数数据管理

📁 数据管理 → 薪酬及社保基数数据

当人员编制数量、平均工资、社保公积金等数据发生变动时，在此处进行修改。部门薪酬费用是预算成本预测的重要输入。

注意：在“计件人工标准数据管理”页面维护的是计件单价的岗位基准，而此页面中的“计件工资”列为系统自动计算，无需手动填写。

3.7 制造费用基础数据管理

📁 数据管理 → 制造费用基础数据

当单位变动费用、预计月固定费用等制造费用相关数据发生调整时，在此处进行修改。制造费用包含水电气、维修、折旧、机物料消耗等项目。

3.8 期间费用基础数据管理

📁 数据管理 → 期间费用基础数据

预计月固定费用、房租物业等费用需按部门做比例分摊时进行调整。主要包括管理费用、销售费用、财务费用等期间费用的预算数据维护。

分摊规则：房租、物业等费用分摊按部门维度进行，在期间费用管理页面维护各部门分摊比例；薪酬费用分摊按现有规则 — 制造部门承担70%、管理/投资部门承担30%。

3.9 税金及附加基础数据管理

📁 数据管理 → 税金及附加基础数据

当房产税、土地使用税月固定值、印花税、所得税、城建税、教育费附加等税率或固定金额有调整时，在此处进行修改。

3.10 基金补贴单价管理

📁 数据管理 → 基金补贴单价

当国家基金补贴标准发生变动时，在此处维护各品类旧机的补贴单价。基金补贴收入是营业收入预测的重要组成部分。

四、采购数据编辑

▼
📁 数据管理 → 提取结果编辑 → 本期计划采购数量 / 本期计划采购单价

编辑本期的物料采购计划数据，包括采购数量和采购单价。系统将基于此数据计算计划投料量和单位投料成本。

首次进入页面时数据为0，需先点击“读取数据并自动计算”进行初始化。列表中的“初始数据”即为期初库存的数据。

操作步骤

  1. 进入页面后如果数据为0，先点击 读取数据并自动计算
  2. 在列表中填写本期计划采购数量和本期计划采购单价，点击保存修改
  3. 批量修改：下载Excel模板 → 填写 → 上传 → 选择“全覆盖”模式 → 点击“确认导入”
  4. 编辑完成后，点击 重新计算 进行重算
  5. 最后点击 同步数据 将结果同步给其他用户

五、旧机投料数据编辑

▼
📁 数据管理 → 提取结果编辑 → 编辑“本期实际投料数量”

在采购数据录入完成的基础上，编辑本期的实际投料数量。投料数量由不同用户填写，在采购数据的基础上进行调整。

系统默认“本期实际投料数量 = 本期计划投料数量 = 初始数据（期初库存）+ 本期计划采购数量”。用户可根据实际生产情况进行人工调整。

操作步骤

  1. 在列表中修改本期实际投料数量列
  2. 修改完成后点击保存修改
  3. 批量导入/导出操作与第四章“采购数据编辑”一致
  4. 编辑完成后点击重新计算 → 同步数据

六、制造费用数据编辑

▼
📁 数据管理 → 制造费用数据编辑

预览并编辑一类拆解物料的相关制造费用，包括转投费用、一类二次/三次加工费用、印刷板处置、荧光灯处置、委外处置等费用。

操作步骤

  1. 进入页面后，点击只读/初始/手工数据切换状态，将只读模式变为可编辑模式
  2. 在第1~6列中对制造费用数据进行修改，完成后点击保存并拆分，系统自动按各物料进行分摊
  3. 批量导入：点击下载模板 → 填写 → 上传Excel → 系统自动识别预览 → 点击确认导入

七、销售价格编辑

▼
📁 数据管理 → 销售价格

编辑和维护拆解产物的销售价格，包括含税单价和增值税率。不含税单价由系统自动计算生成。

操作步骤

  1. 在线编辑：直接点击销售单价-含税(元/KG)和增值税率(%)进行编辑，销售单价-不含税(元/KG)自动计算生成，修改后点击保存修改
  2. 新增记录：点击新增按钮，在新增行填写数据后点击保存
  3. 批量导入：下载Excel模板 → 填写修改 → 上传 → 点击初始化导入
  4. 编辑完成后返回数据管理页面，点击重新计算 → 同步数据

八、可销售量数据编辑

▼
📁 数据管理 → 可销售量数据编辑

编辑各拆解产物的计划销售数量。系统根据减扣规则自动计算可销售量，用户可在此基础上进行手工调整。

操作步骤

  1. 进入页面后，点击加载复核引擎数据，选择初始/手工数据，页面数据更新为当前修改后的数据
  2. 在第1~6列中对可销售量数据进行修改，完成后点击保存并拆分
  3. 批量导入：点击下载货品模板 → 填写 → 点击批量导入数据 → 上传 → 确认导入
  4. 编辑完成后返回数据管理页面，点击重新计算 → 同步数据

九、预算总表（下月）编辑

▼
📁 首页 / 数据管理 → 预算总表（下月）

查看和编辑完整的经营预算汇总表。系统将部分费用数据取为月均标准值后，重新计算季度、半年、年度数据。

操作步骤

  1. 进入预算总表页面，查看系统自动汇总的各项预算数据
  2. 如需调整，直接在对应单元格中修改数据
  3. 修改完成后点击重新计算按钮，系统自动重新汇总季度、半年、年度数据
  4. 最后点击同步数据将编辑结果同步到其他用户

十、数据存档及提取

▼
📁 首页 → 保存快照 / 加载快照

将当前系统中的所有数据保存为快照，存储到服务器或本地，便于后续查阅历史数据或恢复到历史状态。

警告：加载历史快照将覆盖当前数据，请确认当前数据已保存后再执行加载操作。

保存快照

  1. 在首页点击保存快照按钮
  2. 在弹出的信息框中，填写文件名称，选择保存路径
  3. 点击确认保存

加载快照

  1. 在首页点击加载快照按钮
  2. 在弹出的信息框中，选择要提取的历史文件
  3. 勾选我理解加载将覆盖当前数据，确认继续
  4. 点击确认加载，系统自动刷新页面
  5. 若页面无变化，可点击首页的重新计算进行数据加载
