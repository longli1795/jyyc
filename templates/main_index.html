数据来源及计算公式说明
1.1 产物销售收入
来源：销售收入页面 → 可售数据（优先使用手工数据），按分类汇总"销售收益(元)"列
1.2 基金补贴收入
来源：补贴收入页面 → 补贴收入数据，按补贴大类汇总"基金补贴收入(元)"列
1. 营业收入
公式：1.1 产物销售收入 + 1.2 基金补贴收入
2.1 产物销售成本
来源：一次拆解产物成本计算页面 → 按分类统计"一次拆解产物销售成本"字段；深加工产物成本计算页面 → 按四机一脑类别统计"深加工产物销售成本"字段
2.2 基金补贴成本
来源：生产成本分摊页面 → 按产线获取"基金补贴收入分摊成本"
2. 营业成本
公式：2.1 产物销售成本 + 2.2 基金补贴成本
3. 项目毛利
公式：1. 营业收入 - 2. 营业成本
4. 项目毛利率
公式：3. 项目毛利 / 1. 营业收入 × 100%
5. 期间费用
来源：期间费用明细页面 → 期间费用计算，按产值比例分摊到各分类（产值数据来自一次拆解产物产值页面）
6. 税金及附加
来源：税金及附加页面 → 与首页成本预测「税金及附加」卡片一致，取冰箱、空调、电脑、电视、洗衣机各分类合计金额
7. 营业利润
公式：3. 项目毛利 - 5. 期间费用 - 6. 税金及附加
