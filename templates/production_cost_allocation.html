数据来源及计算公式说明
基金补贴收入
来源：基金补贴收入页面 → 按补贴大类汇总的"基金补贴收入(元)"
拆解产物价值
来源：收入预测 → 一次拆解产物产值页面 → 按原物料名称分类汇总的"拆解产物价值"
公式：计算结果(KG) × 销售单价-不含税(元/KG)
直接材料
来源：拆解物原料成本页面 → 按物料描述分类汇总的"拆解物原料成本"（仅旧机类别）
直接人工
来源：直接人工成本页面 → "四机一脑分类统计"卡片各类别的"合计"
公式：计件工资 + 分摊固定成本
制造费用
来源：
1. 制造费用成本页面 → "分类费用汇总"卡片各类别费用
2. + 公共费用分摊明细页面 → "按类别分摊"各类别费用
3. + 成本预测 → 间接人工成本页面 → "制造费用汇总"卡片各类别费用
注：制造费用汇总 = 间接人工成本 - 品管提成 - 叉车司磅库管等提成（及对应分摊固定成本）
基金补贴成本分摊比例 / 拆解产物成本分摊比例
计算方式：基于各产线的基金补贴收入和拆解产物价值占比计算
基金补贴成本分摊比例 = 基金补贴收入 / (基金补贴收入 + 拆解产物价值)
拆解产物成本分摊比例 = 拆解产物价值 / (基金补贴收入 + 拆解产物价值)
生产成本小计
公式：直接材料 + 直接人工 + 制造费用
基金补贴收入分摊成本 / 拆解产物分摊成本
基金补贴收入分摊成本 = 生产成本小计 × 基金补贴成本分摊比例
拆解产物分摊成本 = 生产成本小计 × 拆解产物成本分摊比例
