分摊计算结果
数据来源及计算公式说明
数据来源
制造费用间接人工分摊 + 制造费用公共成本分摊 + 屏费用分摊结果
总费用
= 制造费用间接人工分摊 + 制造费用公共成本分摊 + 屏费用分摊结果
屏费用分摊结果
= 直接人工（屏工资 + 屏分摊）+ 制造费用（屏）（与拆解量相关的费用 + 预计月均费用 + 环保费）
屏费用分摊到电视/电脑
= 屏费用分摊结果 × (电视/电脑重量 / 总重量)
按类别分摊
= 制造费用间接人工分摊类别汇总 + 制造费用公共成本分摊类别汇总 + 屏费用分摊结果（仅限电视和电脑）

制造费用间接人工分摊
数据来源及计算公式说明
数据来源
一次拆解产物产值数据 + 间接人工成本数据（其他岗位）
物料产值
= 计算结果(KG) × 销售单价-不含税(元/KG)
分摊比例
= 物料产值 / 总产值
分摊成本
= 分摊比例 × 岗位成本
特殊规则
11个特定岗位按总产值分摊；黑电保洁仅限电视、电脑类别；白电保洁仅限空调、洗衣机类别
