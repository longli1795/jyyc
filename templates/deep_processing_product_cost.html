数据来源及计算公式说明
深加工产物编码
来源：深加工拆解产物产值页面 → "深加工产物编码"列
深加工产物名称
来源：深加工拆解产物产值页面 → "深加工产物名称"列，或从提取结果数据（类别为"打包铁"或"一破"）的"物料描述"列匹配
四机一脑类别
来源：深加工拆解产物产值页面 → 根据"深加工产物编码"匹配"四机一脑类别"，如果有重复的"深加工产物编码"，按照"深加工拆解产物产值"页"四机一脑类别"分成多行
类别
来源：深加工拆解产物产值页面 → 根据"深加工产物编码"匹配"类别"
期初库存数量
来源：提取结果数据 → 类别为"打包铁"、"一破"、"屏"或"印制板"，按物料代码统计"非限制使用的库存"列，如果有多个类别，默认归类为"电视"
期初库存金额
来源：提取结果数据 → 类别为"打包铁"、"一破"、"屏"或"印制板"，按物料代码统计"价值"列
当期生产重量
来源：深加工拆解产物产值页面 → 按"四机一脑类别"和"深加工产物编码"汇总"深加工结果(KG)"
物料产值
来源：深加工拆解产物产值页面 → 按"四机一脑类别"和"深加工产物编码"汇总"物料产值（元）"
分类产值总数
来源：深加工拆解产物产值页面 → 按"类别"汇总"物料产值"
分类深加工产物分摊成本
来源：一次拆解产物成本计算页面 → 根据类别匹配对应的成本汇总数：
• "打包铁" → "深加工-打包铁（成本）"
• "一破" → "深加工-塑料一破（成本）"
• "屏" → "内转屏处置（成本）"
• "印制板" → "内转印制板处置（成本）"
本期生产成本
公式：每个"深加工产物编码"对应的物料产值 / 分类产值总数 × 分类深加工产物分摊成本
期末单位成本
公式：（期初库存金额 + 本期生产成本）/ （期初库存数量 + 当期生产重量）
如果有重复的"深加工产物编码"，期末单位成本 = （期初库存金额1 + 本期生产成本1 + 期初库存金额2 + 本期生产成本2 + ...）/ （期初库存数量1 + 当期生产重量1 + 期初库存数量2 + 当期生产重量2 + ...）
销售数量
来源：销售收益页面 → 按照"拆解产物编码"统计"计算结果(KG)"，根据"原物料名称"品类映射规则分类到对应的"四机一脑"类别
映射规则：
• 电视：电视、彩电、CRT其它机壳破碎塑料、线路板边框破碎塑料、等离子、废旧玻璃电子枪、废旧金属荫罩压块铁、黑白
• 电脑：电脑、显示器、笔记本、主机、废旧金属黑色金属-铁及其合金-电子枪
• 冰箱：冰箱、冰柜 | 空调：空调 | 洗衣机：洗衣机、双缸
深加工产物销售成本
公式：销售数量 × 期末单位成本
付费处置（数量）
默认全部为0
付费处置（成本）
默认全部为0
期末库存数量
公式：期初库存数量 + 当期生产重量 - 销售数量 - 付费处置（数量）
期末库存成本
公式：期末库存数量 × 期末单位成本
